云网址模式（免本地依赖）

把 Token 放在网址的 # 后面，打开网址即可自动拉取数据，无需任何配置。 数据只在内存中解密，关闭页面后本机不留痕迹——换设备、换浏览器只要记住网址和主密码。

安全提醒：网址里的 Token 会以明文形式出现在地址栏和书签中。 建议给这个 Token 只开读取权限（只读），写入留在本机设置里手动「推送」。 若网址泄露，他人只能看到加密后的密文，没有主密码依然打不开。

Chrome 导出路径：chrome://settings/passwords → 导出。导入后数据仅存在本地，需手动同步。

把「域名 + 用户名 + 密码」完全相同的记录合并，只保留最近更新的一条。此操作会真正删除数据，建议先导出备份。

建议使用 12 位以上，包含大小写、数字和符号。
